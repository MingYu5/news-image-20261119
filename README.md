A newspaper-style infographic summing up the world news of Thursday,
19 November 2026: the Trump–Xi–Putin summit in Shenzhen, the ICJ ruling
that Myanmar committed genocide against the Rohingya, the end of Israel's
first major Gaza ground raid since the 2025 ceasefire, a Houthi missile
hitting Riyadh's tallest tower, a new attack on the Crimean Bridge,
Cyclone Akvan approaching India's east coast, and Ethiopia and Eritrea
on the brink of war. The image is drawn entirely by `main.py` with
Pillow — no photos, no network, no external assets.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (1024×1024, PNG) in the current directory.
With `MAKEFUN_OUTPUT_DIR` set, it writes there instead:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
